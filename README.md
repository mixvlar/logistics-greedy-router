# Задание 6. Библиотека распределения заказов по транспорту

Библиотека для упрощённой диспетчеризации доставки. Есть заказы на отгрузку: у каждого — идентификатор, вес в килограммах, код зоны доставки (строка, например north, center). Есть транспортные единицы: идентификатор, максимальная грузоподъёмность, при желании — строка с базовым пунктом для отчёта. Нужно построить план загрузки: какие заказы назначены на какую машину, суммарный вес по машине, список заказов, которые не удалось распределить ни на одну машину.

## Архитектура проекта

### 1. Header-only часть
* Заказ.
* Машина.
* Одно назначение «заказ $\rightarrow$ машина».
* Итоговый план:
  * назначения;
  * нераспределённые заказы;
  * признак перегруза по машине.

### 2. Статическая часть
* Накопление списков заказов и машин в памяти.
* Построение плана по жадному правилу.

### 3. Динамическая часть (DLL)
* Загрузка заказов и машин из текстового или CSV-файла.
* Запись ведомости загрузки в текстовый файл: по каждой машине — id, список заказов, суммарный вес; в конце — блок нераспределённых заказов.

### 4. Демо-приложение
Связывает модули между собой:
* Загрузка данных через DLL.
* Построение плана в статике.
* Вывод краткой сводки на экран (число машин, сколько заказов распределено, сколько нет).
* Запись ведомости через DLL.

---

## Тестирование

### Тесты статики
* Все заказы помещаются в одну машину.
* Один заказ тяжелее любой машины.
* Несколько машин, часть заказов остаётся нераспределённой.
* Вес заказа ровно равен оставшейся грузоподъёмности машины.
* Пустой список заказов.
